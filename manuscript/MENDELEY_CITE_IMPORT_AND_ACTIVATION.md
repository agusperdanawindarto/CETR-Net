# Mendeley Cite activation: CETR-Net v4

1. Open the revised DOCX in Microsoft Word with Mendeley Cite installed.
2. Import CETR_Net_Mendeley_IEEE_References.bib through Mendeley Reference Manager.
3. Set IEEE numbered citation style in Mendeley Cite.
4. For all in-text numeric citations, select the exact source using Insert Citation; remove static marker only after insertion.
5. Generate a fresh bibliography using Mendeley Cite and confirm numbering follows order of first appearance.
6. Save, close, reopen Word, click several citations and verify the Mendeley fields remain editable.
